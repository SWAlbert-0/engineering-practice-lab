# 开源PLA材料参数核对案例

来源：UltiMaker fdm_materials，Generic PLA profile，CC0-1.0。此文为本项目从固定XML转换的中文检索材料，不是经工艺验证的生产SOP。

材料为Generic PLA。源配置明确说明：数据可能不适用于你的具体机器。使用者应核对打印机、热端和材料版本，不能将通用参数直接作为生产批准。

通用配置字段 print temperature 的数值为 200；温度单位为摄氏度。这是顶层通用配置，具体设备或热端的覆盖值需另查原XML。

通用配置字段 standby temperature 的数值为 100；温度单位为摄氏度。这是顶层通用配置，具体设备或热端的覆盖值需另查原XML。

通用配置字段 heated bed temperature 的数值为 60；温度单位为摄氏度。这是顶层通用配置，具体设备或热端的覆盖值需另查原XML。

附着说明原文：Print on bare glass. Use tape for cold build plates. 本项目未补造预热时长、检验标准或合格阈值。

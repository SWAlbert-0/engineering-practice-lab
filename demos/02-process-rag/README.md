# 工艺资料与草案工作区

原选题：**D01 · 基于 RAG 的轻量级企业工艺生成**（丁箐老师）。

本机单工作区可用首版：实际文档入库后参与检索，证据关联文档版本、页码和段落；草案支持编辑、逐工序核查、版本保留及导出。

## 运行

在仓库根目录选择 Docker、Conda 或 venv 启动，见 [运行方式](../../README.md#运行方式选择)。Docker：

```bash
docker compose up --build -d --wait
```

访问 <http://127.0.0.1:8765/demos/02-process-rag/>。Docker 数据保存在命名卷，本地默认保存在根目录 `data/`，清理浏览器不会删除记录。

## 功能

- UTF-8 TXT、Markdown、文本型 PDF 入库；异步解析、索引、取消、错误重试和历史版本。
- 动态 BM25 / LSA 融合检索，可选预训练嵌入 API；文档替换或删除会更新生效索引。
- 来源回跳原文页及高亮段落；检索历史保存证据快照。
- 离线摘录或可选大模型结构化工艺草案，编辑工序、引用与参数。
- 新版本重新审核；无来源数值/参数需人工依据，来源过期不能通过审核。
- Markdown / JSON 导出，固定快照上的批量检索评估与逐题结果。

## 演示流程

上传 [自编验收资料](samples/import-check.md) → 查看任务 → 检索 `ZXDOC` → 点击证据回原文 → 形成草案 → 修改并保存新版本 → 逐工序核查 → 导出。

可继续上传替换版本或删除该资料，确认旧草案标为来源变化并禁止通过审核。详细架构、接口、备份与限制见 [D01 工作区说明](../../docs/D01_WORKSPACE.md)。页面“项目指南”提供六章说明与架构图。

## 范围

默认八段语料及样例是自编教学资料。LSA 不等于预训练语义嵌入；模型和嵌入模式需要配置服务并产生实际请求。审核记录不构成企业生产批准。当前未提供账户权限、OCR、复杂表格解析或独立工艺保留集评测。

旧 `workbench.html` 与 `engine.py` 保留为固定语料检索基线，新入口使用 `product.js` 和 `shared/process_workspace.py`。

# 塔防

来源：白天 B类第5题。

## 运行

在仓库根目录启动，全部项目共用同一个环境：

```powershell
# Windows PowerShell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

```bash
# macOS / Linux
bash start.sh
```

脚本优先使用当前终端可调用的 Conda，自动创建/复用 `engineering-practice-lab`。无 Conda 时需要 Python 3.10–3.13（推荐3.12），自动创建共用 `.venv`。无需先手动激活，首次安装后会直接启动服务。

访问 `http://127.0.0.1:8765/demos/04-tower-defense/`。环境、端口与检查参数见 [完整部署说明](../../docs/DEPLOYMENT.md)。请通过本地服务访问所有项目功能。

## 演示步骤

打开index.html → 空地建塔 → 开始下一波 → 赚金币继续建塔 → 完成5波；可暂停或重开。

## 本次实现

固定1/60秒逻辑步长、两类塔、目标选择、路径移动、减速、金币、五波、击杀统计、胜负和重置。

## 当前边界

Canvas网页原型；没有Unity/Godot工程、动态寻路、存档、编辑器、资源管理、对象池或压力性能数据。

## 完整项目下一步

迁移至目标引擎；关卡和波次数据化、编辑器、寻路/行为树、存档；做同硬件压力基准，先定位再优化；用可复现回放验证。


## 项目页面与记录

游戏大厅 → 关卡选择 → 图鉴 → 布阵编辑 → 对局 → 战斗记录。

三个关卡共用道路与五波敌人，起始金币/耐久分别为240/20、160/12、130/10。编辑器支持放置、移除、撤销并保存开局塔位，按关卡金币限制校验，方案可带入实际对局。支持1、1.5和2倍速；只有已结束对局会保存战绩。

项目入口是 `index.html`；原计算或游戏页面保留为 `workbench.html`，由项目入口嵌入。新增记录保存在当前浏览器，可在设置页导出或重置，不会自动同步到其他设备。

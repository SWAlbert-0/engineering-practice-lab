# 测试与缺陷修复

原选题：**D11 · 基于大语言模型智能体的自动化软件测试与缺陷修复系统**（丁箐老师）。目录序号不是原题编号。

项目面向固定 Python 教学快照，保存从原始失败、候选修订到测试与人工审查的完整证据。新工作区使用服务端 SQLite；清理浏览器不会删除任务。

## 启动

在仓库根目录执行：

```bash
docker compose up --build -d --wait
```

访问 <http://127.0.0.1:8765/demos/01-repair-agent/>。Compose 自动构建执行镜像并启动独立 worker。无需本机 Python、Conda、Node.js 或模型密钥，默认使用离线候选。

Conda 和 venv 继续使用根目录的一键启动脚本，所有项目共用环境；本地默认只执行内置可信候选。手写和模型源码需使用独立 Docker 运行器。详细差异见 [运行方式](../../README.md)。

## 使用

1. 选择运费边界、平均值空输入或稳定去重快照，核对源码、测试与内容哈希。
2. 创建任务，选择离线、手写或模型候选，设置最多1–3轮；离线“先失败再修订”可查看两轮对比。
3. 系统先复现缺陷，再验证候选。任务页中切换轮次，点击失败用例查看输入、预期与日志。
4. 完整测试通过后审查对应候选；记录认可或退回，下载 `.patch` 与 JSON 证据。
5. 停止任务保留已有证据；重试生成新任务，不覆盖历史。

## 实现

- 持久任务、事务领取、心跳、取消/超时与中断恢复；
- 固定源码和测试快照，路径/大小/语法约束，测试只读；
- 独立 worker 和禁网、只读、限资源的一次性容器；
- 可选模型候选与最多两次修订，失败不伪装成功；
- 基线、diff、每项测试、日志、候选/镜像哈希与人工审查；
- 审查冲突检测、原生下载、跨浏览器读取和完整图文指南。

## 范围

当前是三个原创单函数教学快照，不接受任意 Git 仓库、依赖包或 shell。独立测试公开，尚未完成5个开源仓库/30缺陷的泛化评测；没有多人身份认证或远程 PR 操作。

完整架构、接口、模型预算、隔离边界及备份见 [D11工作区说明](../../docs/D11_WORKSPACE.md)。旧 `workbench.html`、`engine.py` 和 `/api/repair` 保留为可信样例基线，旧浏览器记录可从新工作区设置中下载。

# D12 · 视频观察台

轻量级多模态大模型的视频理解与推理系统的单机工程工作区。

已实现持久视频素材、受限服务端FFmpeg校验与采样、真实播放器和帧时间线、可选视觉模型问答、逐条证据核对、失败/取消/重试、历史采样过期标记及JSON/Markdown导出。页面提供选题介绍弹窗和图文使用指南。

从仓库根目录以现有Docker、Conda或venv任一方式启动，访问`/demos/04-video-understanding/`。所有项目共用现有环境；Docker与Conda包含FFmpeg，venv方式需在系统安装FFmpeg / ffprobe。

先导入教学示例→等待校验→创建采样→点击帧定位→输入问题并离线整理→查看和导出记录。配置视觉服务后才可进行内容问答；离线不会生成画面理解结果。

限制：16 MiB、最长600秒、最多6帧；不处理音频。尚未完成本地轻量模型、量化、两套基准或真实供应商问答质量评估。

完整数据契约、部署、测试与边界见[工作区说明](../../docs/D12_WORKSPACE.md)，三种运行方式见[正式README](../../README.md)。旧`/api/video`一次性帧校验接口继续保留，新页面使用`/api/video-workspace/`。

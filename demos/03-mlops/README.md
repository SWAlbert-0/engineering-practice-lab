# 模型发布实验

来源：丁箐 项目二。

## 运行

在仓库根目录启动，全部项目共用同一个环境：

```powershell
# Windows PowerShell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

```bash
# macOS / Linux
bash start.sh
```

脚本优先使用当前终端可调用的 Conda，自动创建/复用 `engineering-practice-lab`。无 Conda 时需要 Python 3.10–3.13（推荐3.12），自动创建共用 `.venv`。无需先手动激活，首次安装后会直接启动服务。

访问 `http://127.0.0.1:8765/demos/03-mlops/`。环境、端口与检查参数见 [完整部署说明](../../docs/DEPLOYMENT.md)。请通过本地服务访问所有项目功能。

## 演示步骤

默认污染0.65运行 → 观察回滚 → 改为0运行 → 特征偏移2运行 → 取消真实标签运行。

## 本次实现

两个真实CPU逻辑回归模型、固定种子、数据hash、独立训练/验证/当前窗口、PSI、同窗口质量比较、活动模型切换和新预测。

## 当前边界

合成数据；只在本次请求内生效，无数据库或模型注册中心；未接DVC、MLflow、Docker、Prometheus/Grafana和CI/CD。坏候选故意绕过发布门禁用于演练。

## 完整项目下一步

补DVC数据版本、MLflow registry/alias、容器API、指标抓取和仪表盘；发布前验证门禁、金丝雀流量；处理标签延迟；回滚后验证服务真正加载对应模型。


## 项目页面与记录

数据集 → 训练实验 → 模型版本 → 发布审批 → 监控窗口 → 告警处理。

每次实际训练生成两个版本记录。质量下降的候选与缺少真实标签的候选不能进入审批。发布审批、流量比例、发布和回滚仅保存为本地流程状态；监控展示最近一次实验快照，非持续采集。模型权重未持久化。

项目入口是 `index.html`；原计算或游戏页面保留为 `workbench.html`，由项目入口嵌入。新增记录保存在当前浏览器，可在设置页导出或重置，不会自动同步到其他设备。

# 模型发布平台

**D02 · 基于 MLOps 的全链路 AI 模型部署与监控系统**（丁箐老师）。连接数据快照、真实训练、安全制品、实际预测、发布/回滚与窗口监控。

在仓库根目录运行：

```bash
docker compose up --build -d --wait --wait-timeout 90
```

打开 <http://127.0.0.1:8765/demos/03-mlops/>。Docker、共用 Conda 和 venv 三种方式见 [仓库 README](../../README.md)，各项目不单独建环境。

## 当前能力

- UTF-8 CSV导入、不可变数据快照、哈希、修订血缘、预览与质量检查。
- 受限子进程中的实际逻辑回归训练，固定分层切分，训练内标准化、验证指标与JSON权重持久化。
- 质量门禁、人工审核、候选哈希/结构/推理探针、原子活动指针、失败保留旧模型与真实历史回滚。
- 预测接口返回实际模型、部署修订、制品哈希及概率；真实请求计数与Prometheus文本指标。
- 显式窗口、输入质量、PSI分布、标签覆盖、同窗口模型比较、分类告警及处理审计。
- 可选MLflow实验参数/指标/血缘同步，不影响默认使用；制品与服务版本仍由本地工作区管理。
- 深蓝控制室主题、实验比较、目标/加载版本、真实预测、分布图、选题弹窗及六章图文指南，支持窄屏。

首次使用可在数据页创建明确标注的合成教学数据，完成训练→审核→发布→预测→监控→回滚。合成指标不代表业务模型质量。数据和模型保存在服务端 `mlops.sqlite3`；旧教学接口保留兼容，旧浏览器记录不自动转为实际部署。

完整流程、API、限制与备份见 [D02工作区说明](../../docs/D02_WORKSPACE.md)。当前没有外部模型注册/权重上传、Evidently报告、持续流量采集、生产负载基准、多实例灰度或账户权限。

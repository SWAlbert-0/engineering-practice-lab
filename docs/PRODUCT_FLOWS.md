# 项目页面与交互流程

更新：2026-10-19。五个项目使用独立导航和 hash 路由，默认通过同一个 Docker 容器提供服务。本地开发仍可使用共用 Conda 或 .venv。安装与启动见 [部署说明](DEPLOYMENT.md)，原选题编号与实现目录对应关系见 [五个选题说明](PROJECTS.md)。

## 通用行为

- 导航可返回概览、列表与详情；页头可切换项目。
- 列表支持按当前行文本筛选，未匹配时有空状态。
- 表单使用必填校验，提交期间锁定按钮；失败时显示原因。
- 五个项目均使用服务端工作区，同一数据目录下跨浏览器共享。旧教学LocalStorage记录不会自动迁移。
- 初始示例单独标记。D01/D09 直接使用业务 API，其他项目真实计算结果经同源 iframe 消息传入页面并保存；拒绝其他窗口或不同来源的结果消息。
- 存储不可用或超出容量时明确提示，当前会话仍可继续，建议导出备份。
- 页面采用五套独立响应式主题；已通过 Firefox 桌面与窄屏检查，尚未做手机硬件实测。各项目顶部“选题介绍”可查看题目要求、评分、风险和实现范围。

## 测试与修复

D11 使用服务端任务和证据库。首页、任务创建、任务列表、代码/测试快照、差异/测试/事件/审查详情、教学样例统计、设置和六章图文指南构成完整操作入口。

1. 选择固定快照并创建任务，先复现原始缺陷。
2. 离线、手写或模型提供候选；手写/模型源码只在独立 Docker 模式开放。
3. 最多三轮候选，每轮保留统一 diff、来源、回归和独立验收。失败用例联动实际输入、预期和日志。
4. 执行结果与人工审查独立；认可绑定完整通过的候选哈希与当前任务修订号，失败轮次和旧页面不能误认可。
5. 下载补丁/JSON，停止任务或显式新建重试。重试不覆盖历史、不继承认可，也不自动操作远程 GitHub。

数据位于 `repair.sqlite3`，Docker 使用共享命名卷。worker 单独持有 Docker socket；每个测试容器禁网、只读且限制资源，没有宿主或工作区挂载。Conda/venv 仍只执行内置可信代码，旧浏览器记录可下载备份。范围、恢复与API见 [D11说明](D11_WORKSPACE.md)。

## 工艺资料与草案工作区

D01 已改为服务端持久化入口，不再使用 iframe + LocalStorage 保存业务数据。导航包括概览、资料目录、导入、文档版本、检索、检索记录、草案审核、任务、评估、索引与数据及指南。

首页可直接检索，按材料分类打开资料，并继续待核对草案。

1. 上传 TXT/Markdown/文本型 PDF，后台解析并建立快照；成功后新文档可检索。
2. 替换版本成功后切换有效来源，失败保留原版；删除从索引移除，历史仍可追溯。
3. 检索记录固定索引和来源版本，点击证据打开原文页及高亮段落。
4. 形成离线或可选模型草案，编辑工序、引用与参数后保存为新版本。
5. 逐工序核对并记录审核身份与意见；版本冲突、来源过期、未确认数值或参数阻止通过。
6. 导出 Markdown/JSON；评估固定快照上的命中与拒答，并保存逐题结果。

记录保存于 SQLite；Docker 使用命名卷，本地使用 `data/`。旧浏览器工作区可完整导出，未索引文本可迁入服务端；旧审核不会自动升级为新版审批。完整限制、备份与接口见 [D01说明](D01_WORKSPACE.md)。

## 旧版模型发布实验（兼容教学基线）

页面：概览、数据集列表/结构、实验列表/运行/详情、版本列表/详情、发布列表/创建/详情、监控窗口、告警列表/处理、设置、指南。

实验与发布流程：

1. 查看训练、验证与当前窗口的用途，运行实际逻辑回归训练。
2. 保存实验参数、准确率、PSI、预测样本和数据标识，同时生成 v1/v2 版本记录。
3. 质量下降的 v2 或没有当前真实标签的 v2 不能进入发布审批。
4. 选择合格版本，填写环境、模拟流量比例与变更说明。
5. 审批后进入“模拟发布中”，可记录“已模拟回滚”。这些状态不会更改真实推理服务。
6. 监控页展示最近一次实验快照；质量下降、漂移或无标签会产生本地告警，填写结论后标记已处理。

实验内回滚会实际使用 v1 重新预测。发布页是另一套本地流程状态，未连接 MLflow、独立模型容器或真实流量。当前只保存指标与记录，不保存模型权重。

## 需求设计台

首页直接输入或读取文件并固定原文版本 → 持久分析任务 → 带来源的用例集 → 并排编辑/自动草稿 → 提交新版本 → 按确认数量审核 → 发布不可变快照 → CSV/JSON/Markdown 导出与 JSON 回导。

用例编辑采用原文、用例目录和编辑器并排布局；目录切换前先保存当前草稿，窄屏保留用例选择器。操作、输入与预期分列填写；待确认问题可展开查看。核对区支持全选与选择数量提示。追踪矩阵按验收条件定位原文和用例；原文修订标记文本受影响需求。跨浏览器冲突返回 409，窗口支持比较本地与服务端、下载本地修改、读取服务端。旧版本和审核保留，新版本需重新核对。完整说明见 [D09工作区](D09_WORKSPACE.md)。用例没有执行被测系统，语义覆盖与100样例双人评测待完成。

## 文献研读室

固定问题与摘记池 → 离线/单次综合/并行阅读 → 引用位置核验 → 逐条人工核对 → 整篇审核。新登记文献待接入；内置摘记不是全文，位置匹配不表示语义支持。

## 开发结构

- `shared/product/core.js`：路由、页面组件、存储、表单事件与工作台消息桥接。
- `shared/product/style.css`：公共组件；`themes.css`、`themes.js`：独立主题与首页；`topics.js`：选题介绍数据。
- `shared/product/guides-data.js`：五项目指南内容；`guides.js`、`guides.css`：图示、章节与排版。
- `shared/product/workspace-ui.css`、`workspace-icons.js`：D01/D09/D11 共用的表单、状态、弹窗、键盘焦点和本地图标；各自 `workspace.css` 定义独立布局与主题。
- D01/D09/D11 的 `workspace.js`：服务端工作区页面与交互；其他项目的 `product.js`：页面定义、初始数据与操作流程。
- 各项目 `workbench.html`、`app.js`：实际计算界面。
- 原 Python 引擎与接口保持原有职责，Windows UTF-8 修复继续生效。

验证命令与边界见 `VALIDATION.md`。新增页面没有引入前端框架、构建工具或额外运行依赖。


## D13 文献与综述工作区

文献库/导入 → 专题筛选 → 原文阅读/证据矩阵 → 确认提纲 → 生成/编辑章节 → 引用核对 → 发布快照。任务页显示阅读或写作节点、已完成输出、取消/显式重试和失败原因。

新记录保存在服务端 SQLite。资料版本、筛选或证据变化会使旧草案过期，禁止继续审核发布；已发布快照与旧来源独立保留。编辑自动保存草稿，提交后形成新版本；冲突时保留本地内容并提供 JSON 下载。

阅读器支持文献版本、提取页和逐字片段定位；矩阵与章节引用均可打开原文窗口。原文/摘要/阅读摘记范围持续可见，离线摘录与模型阅读分别标明。完整流程与限制见 [D13说明](D13_WORKSPACE.md)。


## D02 模型发布与监控工作区

数据快照 → 创建训练实验 → 固定质量门禁/人工审核 → 加载目标版本 → 实际预测 → 监控窗口/告警 → 手工回滚/再次预测。

新版入口使用服务端SQLite，真实权重和活动指针跨浏览器/重启保存。候选加载失败或活动修订变化时不覆盖服务；响应返回实际模型及哈希。窗口冻结模型、数据、样本与阈值，缺标签不计算准确率。人工告警操作有修订和历史，关闭告警不自动换模型。

深蓝顶部导航和控制室区别于文献/工艺/需求主题；目标与加载状态、实验对照、预测结果、分布原始计数均有真实来源。详情、限制与备份见 [D02说明](D02_WORKSPACE.md)。

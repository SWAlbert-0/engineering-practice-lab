# 六项目功能体验引导

启动任一共用部署环境后，打开项目首页，点击 **“跟着做一遍”**。桌面展示当前操作和全部步骤，手机可展开步骤表；每步都说明“做什么”和“应该看到什么”。点击“打开本步功能”进入实际工作页，“定位操作位置”将滚动并突出显示相应控件。

第一次可以使用离线模式和教学资料，不需要模型密钥。各项目仍有选题介绍窗口及需求分析、架构、代码入口、任务流程等六章图文指南，可从“完整图文指南”进入。

| 项目 | 步数 / 参考时间 | 起点和完整体验 |
|---|---|---|
| D01 工艺资料检索 | 6 / 8–12分钟 | 从引导下载教学Markdown并上传；检索原句、核对条件、形成草案、逐工序修改/审核、导出，再替换资料观察来源过期 |
| D02 模型发布平台 | 6 / 10–15分钟 | 创建种子42教学数据、训练、审核加载、发起实际预测、比较干净/偏移/无标签窗口、处理告警并体验历史回滚 |
| D09 需求设计台 | 6 / 8–12分钟 | 填入考勤样例并保存、规则分析、修改用例草稿并提交版本、追踪原文、人工审核、发布导出与需求变更 |
| D11 测试与修复 | 6 / 8–12分钟 | 阅读快照的失败输入、创建“先失败再修订”离线两轮任务、联看测试/日志/diff、审查候选、生成两个任务的固定对照并导出 |
| D12 视频观察台 | 6 / 6–10分钟 | 导入实际教学视频、服务端固定采样、点击帧跳回原片、保存离线采样记录、回看/可选模型证据核对、下载并改变采样 |
| D13 文献研读室 | 7 / 12–18分钟 | 创建专题、导入材料并筛选、阅读与证据核对、文献/证据关系对照、写作前检查、论述支持核对、发布导出及来源变化 |

页面跳转到最近的真实业务记录；还没有记录时先进入列表或创建页。若你切换到另一条记录，请以实际选中的任务、专题和版本为准。创建、训练、运行、审核和发布仍由你在业务页面明确操作，引导不会自动代做。

完成一项后，亲自检查预期现象，再点击“已看到预期结果，下一步”。进度只保存在当前浏览器，并明确标为“自行确认”；刷新可继续，也可收起或重新体验。它不是服务端验收状态，不替代测试、证据审核、真实模型质量或课程评分。

D11完整Docker隔离执行需要可用Docker与worker；Conda/venv只运行既有可信教学候选。D12需要FFmpeg/ffprobe，Docker与Conda已包含。D13的教学文本是虚构材料，离线阅读/写作仅摘录编排；D12离线记录没有视觉回答。需要真实模型时先按[模型配置](MODEL_SETUP.md)配置，再明确选择模型模式。

## 已验证的体验

`tests/test_experience_guide_browser.cjs`在六项目中检查入口、实际跳转和高亮、无自动业务POST、手动进度、刷新/重置及390px布局，并通过引导创建D11实际两轮离线任务。最终[容器浏览器CI](https://github.com/SWAlbert-0/engineering-practice-lab/actions/runs/39409631847)全部通过，截图在该运行的`d01-browser-evidence`工件中。每项目的原功能浏览器套件继续覆盖更完整的业务路径和重启持久化，详见[验证记录](VALIDATION.md)。

# 实施任务清单

基准日期：2026-10-20。本清单保留最初的规划任务与依赖。D01、D02、D09、D11 和 D13 已交付本机工作区首版。D11 已实现固定教学快照、持久任务、独立 Docker worker、有限修订、回归证据与补丁审查；新增固定5仓库/30历史缺陷研究CLI与隔离复现，真实模型修复质量与网页外部 Git 接入待完成。D09 完成原文版本、结构化生成、自动草稿与冲突、追踪审核、发布导出与回导；D09-05 的功能验收已增加，100 条业务分组数据和双人质量标注仍待完成。D01 覆盖文档入库、版本与动态索引、可选模型/嵌入、草案编辑审核、导出和评估工具。D01-05 的独立保留集与工艺语义质量评测尚未完成；共用 FastAPI/ORM、独立 worker 与权限仍待后续迁移。当前范围见 [D01说明](D01_WORKSPACE.md) 、[D09说明](D09_WORKSPACE.md) 和 [D11说明](D11_WORKSPACE.md)，D13 已实现实际文件、证据矩阵、分阶段任务、章节编辑与审核发布，跨领域质量评估待完成，见 [D13说明](D13_WORKSPACE.md)。D02已交付数据/制品、真实服务/回滚、窗口与告警；外部注册、Evidently和生产质量/负载基准待完成，见 [D02说明](D02_WORKSPACE.md)。下表工时为原规划估计，不能当作实际投入。

任务来自 [参考调研与完善计划](RESEARCH_AND_ROADMAP.md)。小时为开发估算，不包含 25% 缓冲。P0 为共用基础，P1/P2 为交付顺序；每项独立通过完成条件再进入发布。

共用层主要落点：计划新增 `backend/`（API/领域服务/仓储）、`worker/`（队列/节点执行）、`migrations/`；`shared/product/` 负责渐进界面改造。项目特有页面和指南继续保留在对应 `demos/` 目录。目录仅为建议，尚不存在时不表示遗漏。

任务完成前保持 planned 或 in_progress，不以页面数量、代码行数或模拟结果替代完成条件。跨项目共用的能力只估算一次；项目任务包含其适配和验收。新增范围需写明估算增量，不从既有任务中静默挤占。

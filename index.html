本地启动

Windows PowerShell，在仓库根目录执行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1

macOS / Linux：bash start.sh。优先使用 Conda 自动建环境；没有 Conda 时使用 Python 3.12 创建共用 .venv。首次安装后直接启动。
